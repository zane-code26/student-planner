# Планировщик учебных задач

Небольшой учебный проект для хранения задач по предметам в одном месте.
Список задач находится в файле tasks.md. Работа с проектом показывает
использование Git: коммиты, ветки, слияние и обмен с удалённым репозиторием.

## Возможности планировщика

- Хранение списка учебных задач.
- Просмотр задач по учебным предметам.
- Отметка выполненных задач.

## Текущая версия

1.0

## Целевая аудитория

Планировщик предназначен для студентов, которым нужно хранить задания
по нескольким предметам в одном месте и следить за их выполнением.

## Как пользоваться планировщиком

1. Открыть файл tasks.md и посмотреть список учебных задач.
2. Добавить новое задание или изменить существующее.
3. Указать приоритет и срок выполнения, когда они нужны.
4. После выполнения отметить задачу и сохранить изменения коммитом Git.
